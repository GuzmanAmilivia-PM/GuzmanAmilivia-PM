## Guzman Amilivia

Project Manager and Industrial Mechanical Engineer based in Montevideo, Uruguay. I manage industrial CAPEX, MEP and HVAC projects, and I build my own software tools on the side.

### Things I've built

**Assembly Plant 3D Simulation** · interactive layout study  
Browser-based 3D model of a truck assembly plant, built with Three.js. It covers KD unpacking and storage, the assembly line, end-of-line testing, PDI, rework and yard logistics, with animated material and vehicle flow. Three site layout scenarios are generated from one set of shared modules. Private repo.

**GA Portfolio Tracker** · personal investment tracker  
Installable PWA with a Cloudflare Workers + D1 backend. It syncs with several brokers and bank accounts, runs scheduled jobs for prices and alerts, and benchmarks performance against the S&P 500. Covered by an automated test suite.  
Frontend: [ga-launcher](https://github.com/GuzmanAmilivia-PM/ga-launcher) · Backend: private

**PMP Exam Simulator** · study tool for the PMP exam (ECO 2026)  
Bilingual (ES/EN) web app in React and TypeScript, with original practice questions. It covers the eight question formats of the 2026 exam, includes a full 180-question timed mock, and syncs progress across devices. Private repo.

**Invoicing & Tax Tracker** · in progress  
Tracks income, social security contributions, VAT and income tax for an independent professional in Uruguay. Spec and test cases are defined; the build is under way. Private repo.
